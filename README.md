# 桌面时钟 (Desktop Clock)

一个基于 Electron 打造的精美 Windows 桌面悬浮时钟应用，支持毛玻璃外观、星期置顶与系统托盘功能。

## 🚀 功能特点

- 🕒 **实时时钟**：精确显示当前时间与星期。
- 🎨 **毛玻璃外观**：简洁精美的半透明视觉效果。
- 📌 **窗口置顶**：方便随时查看时间。
- 🔔 **系统托盘**：支持最小化到系统右下角托盘运行。

## 📦 安装与运行

### 1. 开发环境运行
```bash
# 安装依赖
npm install

# 启动应用
npm start
```
### 2. 打包为安装包
```bash
# 生成安装程序 (DesktopClock Setup 1.0.0.exe)
npm run dist
```
